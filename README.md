## 📋 Descripción del Proyecto

Este es un portafolio profesional de un desarrollador front-end especializado en crear sitios web atractivos, dinámicos e intuitivos. El proyecto incluye:

- **Presentación Personal**: Información sobre mi experiencia y especialidades
- **Portafolio de Proyectos**: Galería de trabajos realizados
- **Habilidades Técnicas**: Stack de tecnologías y herramientas que domino
- **Certificados**: Estudios y certificaciones obtenidas
- **Contacto**: Formulario para comunicarse conmigo

---

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica y accesible
- **SASS**: Preprocesador CSS para estilos avanzados
- **JavaScript**: Interactividad y efectos dinámicos
- **jQuery**: Manipulación del DOM
- **Lightbox**: Galería de imágenes interactiva
- **AOS (Animate On Scroll)**: Animaciones al hacer scroll
- **Google Analytics**: Seguimiento de datos

## 💻 Cómo Usar Localmente

1. **Clonar el repositorio**
   ```bash
   git clone https://github.com/tuusuario/portafolio.git
   cd portafolio
   ```

2. **Abrir en un servidor local**
   - Con Python: `python -m http.server`
   - Con Node.js (Live Server): `npx live-server`
   - O simplemente abre `index.html` en tu navegador

3. **Compilar SASS** (opcional)
   ```bash
   sass css/style.sass css/style.css
   ```
